\# HealthBridge

\### Smart Clinic Management and Queue Automation System



HealthBridge is a Java-based clinic management system designed to simplify clinic operations through patient and doctor management, appointment scheduling, smart queue automation, medical records, prescriptions, billing, and report generation.



\## Project Modules



1\. Patient \& Doctor Management

2\. Appointment \& Smart Queue Management

3\. Medical Records \& Prescription Management

4\. Billing, Payments \& Report Generation



\## Technology Stack



\- Java

\- Java Swing (Frontend)

\- MySQL (Database)

\- JDBC (Database Connectivity)

\- Maven (Project Management)

\- Git \& GitHub (Version Control)



\## Project Status



Currently under development.
